## 部署操作

`bun scripts/deploy-botchain.ts prepare` 仅只读检查、模拟创建并保存计划。RPC 固定为 `https://rpc.botchain.ai`，部署 nonce 固定为本次批准的 `0`，native value 固定为 `0`。gas 总费用上限为 0.02 BOT。

审查通过后，使用受控环境变量 `BOT_DEPLOY_PRIVATE_KEY` 与 `BOT_DEPLOY_APPROVED_DATA_HASH` 执行 `send`。不得将私钥粘贴到命令行或存入追踪文件。脚本校验签名地址，先持久保存原始签名交易再广播，重试只允许相同交易，任何条件变化均停止。

`bun scripts/deploy-botchain.ts verify` 不签名、不广播，读取既有交易并核验 receipt、部署地址、运行时代码（含 immutable token）、管理员/执行权限、暂停状态和零 USDT 余额。

`.local/botchain-deploy/` 中的计划和签名日志是恢复依据。广播后不能删除日志来重新部署；结果不明时先查同一哈希。公开证据放 `docs/evidence/`，不包含私钥或原始签名日志。
